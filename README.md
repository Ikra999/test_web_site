# ChessHub

Шахматы онлайн: обычные, Atomic, Antichess, «Хаос» (17 модификаторов) и партия на четверых.
Хостинг: GitHub Pages, онлайн через Firebase Realtime Database.

## Файлы
- `engine.js` — движок для 2 игроков, `engine4.js` — движок на четверых (доска-крест 14×14)
- `app.js` — интерфейс, лобби, комнаты, онлайн; `pieces.js` — фигуры и иконки; `sound.js`, `style.css`
- `favicon.svg`, `favicon.ico`, `favicon-32.png`, `favicon-192.png`, `apple-touch-icon.png` — иконка сайта

## Firebase
Партия на четверых использует новую ветку базы `rooms4` (комнаты ожидания). Если вы настраивали правила
базы вручную, разрешите чтение и запись в `rooms4` так же, как для `seeks` и `games`.

## После обновления
В `index.html` у скриптов стоит `?v=3`. Когда меняете файлы, увеличивайте число, чтобы браузеры не держали старый кэш
(игроки с разными версиями кода видели бы разные модификаторы «Хаоса»).
